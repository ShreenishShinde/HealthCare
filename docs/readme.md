# Health Care - Food Scanner

An Android application that scans packaged food barcodes and evaluates their healthiness.

Features:
- Barcode scanning
- Open Food Facts API integration
- Health score generation
- Ingredient analysis
- User-friendly explanations

Tech Stack:
- Android Studio
- Java/Kotlin
- Open Food Facts API

Future Improvements:
- AI-based recommendations
- Personalized nutrition analysis
- Sustainability score
